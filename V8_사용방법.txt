수학놀이터 V8

기준본: V6.5 정상 구조를 유지하고 필요한 부분만 수정했습니다.

1. 2단계
- 기존 2단계 함수를 확장하여 5+5=10, 10묶음 2개=20, 3개=30을 먼저 설명
- 이후 10/20/30 중 하나를 목표로 사과를 하나씩 '끌어서' 5칸 배경 수판으로 이동
- 10개마다 10개 묶음으로 표시
- 2단계도 다른 단계와 같이 10문제 흐름에서 다음 문제로 이동
- iPad Safari의 Pointer Events 사용

2. 받아올림
- 두 숫자 모두 십 묶음/낱개로 도식화
- 일의 자리 두 수를 각각 5칸 배경 수판으로 표시
- 10개가 모이면 10개 묶음 1개가 되는 설명 추가
- '10개 묶음 1개 = 사물 10개'를 시각적으로 표시

3. 받아내림
- 빼지는 수와 빼는 수 모두 도식화
- 일의 자리 두 수를 각각 5칸 배경 수판으로 표시
- 받아내림이 필요한 경우 십의 묶음 1개를 실제 사물 10개로 풀어 보여줌
- '10개 묶음 1개 = 사물 10개'를 시각적으로 표시

4. 기존 다른 단계
- V6.5 기준의 기존 코드와 흐름을 유지했습니다.
